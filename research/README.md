# research/ — исследовательский инструментарий

Здесь живёт всё, что относится к экспериментам и замерам, а не к боевому коду:

- `bench/` — бенчмарки моделей и пайплайна (сравнение VLM/OCR-моделей, reasoning-модели,
  embedding-модели, uncensored-LLM для RAG). Запуск: `uv run python -m research.bench.<имя>`
  или `uv run python research/bench/<имя>.py` — см. докстринг каждого скрипта.
  Результаты прогонов (`*_results.json`, `*_report.md`) пишутся рядом.
- `botkin_research_report.docx` — исследовательский отчёт по проекту.

Правила:
1. Код из `src/botkin/` НЕ импортирует ничего из `research/` (обратное — можно).
2. Ничего отсюда не попадает в прод-образ Docker (см. `.dockerignore`).
3. Публикации и журналы экспериментов — в `habr/`; актуальная документация продукта — в `docs/`.
