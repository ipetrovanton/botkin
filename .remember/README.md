# Handoff-файлы: перенос состояния между сессиями и компьютерами

Эти файлы предназначены для стартовых хуков Devin/Claude: они читаются в начале сессии, чтобы
продолжить работу с того же места, и дописываются по ходу работы.

- `remember.md` — основной снимок: текущая цель, что сделано, что сломано, следующий шаг.
- `now.md` — хронологические чекпоинты (append-only): timestamp, ветка, HEAD, числа тестов.
- `last-stop.md` — автоснимок системы (Devin-harness), не редактируется вручную.

## Перенос на другой компьютер

Файлы закоммичены в `master`, поэтому достаточно стандартного git-флоу:

```bash
git pull origin master
# стартовый хук читает .remember/remember.md и .remember/now.md
```

## Сохранение состояния в конце сессии

```bash
scripts/sync-handoff.sh "docs(handoff): session checkpoint"
```

Скрипт закоммитит и запушит изменения в `.remember/` и `habr/`.

## Важно

- Не оставляйте `.remember/`-изменения незакоммиченными — на другом компьютере их не будет.
- `habr/YYYY-MM-DD--*.md` и `habr/lab-results-journal.md` — фактура для статей; их тоже нужно
  коммитить и пушить, иначе находки потеряются.
- `stash@{0}` и незакоммиченные worktree-изменения — не способ перенести контекст: их нет в git.
